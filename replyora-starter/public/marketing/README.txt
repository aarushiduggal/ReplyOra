=================================

Drop real photos into THIS folder (public/marketing/) using the EXACT
filenames below. No code changes are needed — the site picks them up
automatically. Until a file exists, its tile shows a tasteful brand
gradient instead of a broken image, so every page always looks finished.

TIPS
  - Use JPGs, roughly portrait or square, ~1200px on the long edge.
    founder.jpg reads best as a 4:5 portrait.
  - Warm, editorial, on-brand imagery reads best against the palette.
  - Filenames are case-sensitive and must match EXACTLY.
  - The site is designed to look intentional with only founder.jpg +
    brand-1.jpg + brand-2.jpg present — the work-N slots are a bonus.
  - The old /founder-aarushi.jpg is no longer used; put the portrait at
    public/marketing/founder.jpg instead.
